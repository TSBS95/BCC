A Windows 11 effect manager for VEGAS Pro 23 with a simple white and dark grey interface.

Download **BCC-FX-Manager-Setup.exe** below. The ZIP is the portable alternative.

- Search your imported BCC+, BCC, Sapphire, and other VEGAS video effects.
- Save folders and favorites; mirror them into the included dockable VEGAS panel.
- Describe scenes for offline effect suggestions.
- Read actual plugin numeric controls, edit starting values, and send selected settings to VEGAS.
- Apply effects to selected video events with a VEGAS undo block.
- Back up and restore your library.

Connect through the app's **Connect VEGAS** instructions. Keep the exported script and its .config file together. Run it through VEGAS Tools > Scripting > Run Script each time VEGAS starts.

Preview: unsigned installer. Real Windows 11/VEGAS Pro 23 and Boris plugin integration still needs acceptance testing. The folders appear in our VEGAS panel, not the built-in Video FX browser. Suggestions are heuristic starting points, not footage analysis or verified presets. Paid plugins are not included. See README for full setup, behavior, and test limitations.
