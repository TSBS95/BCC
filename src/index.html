ONE-TIME SCRIPT SETUP

Connect to VEGAS.

  1. Save the connection scriptClick Save script below. Keep the file somewhere easy to find.
  2. Run it in VEGAS Pro 23Go to Tools → Scripting → Run Script and select BCC-FX-Manager.cs.
  3. Keep the BCC FX Manager panel openYour installed effects and folders appear in the panel. Return here to search, organize, and apply effects.
Run the script again after restarting VEGAS. Folders appear inside our dockable VEGAS panel; the built-in Video FX browser stays separate. First-use compatibility still needs testing on VEGAS Pro 23.

Backup & help

Back up your folders and favorites before moving PCs. Restoring a backup replaces your current folders and favorites, but never changes installed plugins.

Using the VEGAS panel

Select video events on the timeline before applying an effect. The app adds a new effect instance to every selected video event. Use VEGAS Undo to remove the operation. Your folders are mirrored into the BCC FX Manager panel while it is open.

About suggestions

The local suggestion database matches scene descriptions to installed effect names. Numeric ideas use controls and ranges read from your actual plugin; they are editable starting points, not tested presets. Unsupported controls remain available in VEGAS.

Starting settings

Read your plugin’s numeric controls, then select values to apply.

Without selected settings, the default effect will be applied.

Select your video events in VEGAS first. Applying adds a new effect to each selected video event. Use VEGAS Undo to remove it.
